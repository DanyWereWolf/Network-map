# Установка — Карта оптической сети (Portable)

Краткая инструкция для сервера заказчика. Подробности для разработчиков — в `README.md`.

## 1. Требования

| Что | Нужно |
|-----|--------|
| ОС | Windows, Linux или macOS (x64 / arm64) |
| Интернет | На **первом** запуске (скачивание Node.js и npm-пакетов) |
| Node.js | ≥ 20.9 — **не обязательно** ставить вручную |
| Права | Запись в папку приложения (создание `data/`, `node_modules/`, `.runtime/`) |

Если системного Node.js нет или он старый, `run-api.bat` / `run-api.sh` сами скачают portable Node (~30 МБ) в папку `.runtime/node/`.

## 2. Установка и запуск

1. Распакуйте архив на сервер (желательно путь без кириллицы и пробелов, если возможны ограничения ОС).
2. Запустите:

   **Windows:** двойной клик по `run-api.bat` (или из cmd).

   **Linux / macOS:**

   ```bash
   chmod +x run-api.sh
   ./run-api.sh
   ```

3. Дождитесь окончания первого запуска. Скрипт:
   - при необходимости скачает Node.js;
   - установит зависимости npm;
   - создаст `server-config.json` и каталоги `data/`.
4. В окне консоли появится адрес, например: `http://localhost:3000`.

Остановка сервера: `Ctrl+C` в том же окне.

## 3. Активация лицензии

1. Откройте в браузере: `http://localhost:3000/license.html`  
   (с другого ПК в сети — `http://IP_СЕРВЕРА:3000/license.html`).
2. Скопируйте **код машины** и передайте поставщику.
3. Получите файл лицензии, вставьте его на странице активации.
4. После успешной активации откройте вход: `/auth.html`.

Лицензия бессрочная и привязана к этому компьютеру (проверка без интернета). Файл хранится в `data/license.json` — не удаляйте его.

При переносе на другой сервер запросите у поставщика **перевыпуск** лицензии.

## 4. Первый вход

Учётная запись bootstrap создаётся при пустой базе. Значения по умолчанию (или из `server-config.json`):

| Поле | По умолчанию |
|------|----------------|
| Организация | `Организация` |
| Логин | `admin` |
| Пароль | `admin123` (в клиентской сборке может быть `CHANGE_ME_ON_INSTALL`) |

**Сразу смените пароль** в настройках пользователей и в `server-config.json` (`bootstrapAdminPassword`).

## 5. Настройки после установки

Файл `server-config.json` (создаётся из примера при первом запуске):

| Ключ | Зачем |
|------|--------|
| `port` / `host` | Порт и адрес прослушивания (по умолчанию порт `3000`) |
| `mapEngine` | `yandex` или `leaflet` |
| `yandexMapsApiKey` | Ключ Яндекс.Карт (если нужны онлайн-слои) |
| `bootstrapAdminUsername` / `Password` | Первичный админ |
| `organizationName` | Название организации |

Данные карты и пользователей: `data/store.json` (или MySQL, если в конфиге `storage: mysql`).

## 6. Доступ из сети

1. В `server-config.json` при необходимости укажите `"host": "0.0.0.0"`.
2. Откройте порт в файрволе ОС / на роутере.
3. Открывайте `http://IP_СЕРВЕРА:ПОРТ`.

## 7. Обновление версии

1. Остановите сервер (`Ctrl+C`).
2. Сделайте копию папки (или хотя бы `data/` и `server-config.json`).
3. Распакуйте новый архив поверх / рядом и перенесите `data/` и `server-config.json`.
4. Запустите `run-api.bat` / `run-api.sh` снова (зависимости подтянутся при необходимости).

Не копируйте между машинами/ОС папки `.runtime/` и `node_modules/` — их скрипт создаст заново.

## 8. Типичные проблемы

| Симптом | Что проверить |
|---------|----------------|
| Не скачивается Node.js | Интернет, прокси, антивирус; либо поставьте Node ≥ 20.9 вручную с https://nodejs.org |
| Ошибка npm / native-модулей | Права на запись; на Linux — сборка под текущую ОС (`rm -rf node_modules` и снова запуск) |
| Порт занят | Смените `port` в `server-config.json` |
| Страница лицензии / входа не открывается | Сервер запущен? Верный IP и порт? Файрвол? |
| Нужна лицензия на новом ПК | Новый код машины → перевыпуск у поставщика |

## 9. Поддержка

При обращении укажите:
