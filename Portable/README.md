# Карта оптической сети — Portable (on-prem)

Урезанная версия для установки на сервер заказчика. Без облачного SaaS: нет лендинга, платформенной админки, регистрации, подтверждения e-mail и политики ПДн.

## Что есть

- Вход (`auth.html`) и карта (`index.html`)
- Одна организация на инстанс
- Настройки организации после входа (название, контакт, embed, Zabbix, курсоры)
- Пользователи организации (создаёт админ в UI)
- Карта, sync, бэкапы, ортофото/basemap, Zabbix, embed, org-chat

## Что убрано

- Админ-панель платформы (`site-admin`)
- Главная / тарифы / checkout / новости
- Регистрация и подтверждение почты
- Политика ПДн, cookie-баннер, чат поддержки
- SMTP и «забыли пароль» по почте (сброс — через админа организации)
- 2FA / блок «Безопасность» (вход только по логину и паролю)

## Требования

- Node.js **≥ 20.9**
- Для ортофото (Leaflet): пакеты `geotiff`/`sharp` ставятся через `npm install` **на целевой ОС**

## Быстрый старт

При **первом** запуске скрипты сами:

1. проверяют Node.js ≥ 20.9;
2. ставят зависимости (`npm install --omit=dev`, в т.ч. `argon2` / `sharp` под эту ОС);
3. создают `server-config.json` из примера;
4. создают каталоги `data/` (бэкапы, аватары, basemap, медиа);
5. печатают логин/пароль bootstrap-админа.

### Windows

1. Скопируйте папку `Portable` на сервер.
2. Запустите `run-api.bat` (двойной клик или из cmd).

### Linux / macOS

```bash
cd Portable
chmod +x run-api.sh
./run-api.sh
```

Вручную (то же самое):

```bash
npm install --omit=dev
npm run api
```

(`npm run api` перед стартом вызывает `ensure-first-run`.)

Откройте в браузере: `http://localhost:3000` (или IP сервера; порт — в `server-config.json`).

## Первый вход

При пустой базе сервер создаёт:

| Поле | Значение по умолчанию (из конфига) |
|------|-------------------------------------|
| Организация | `organizationName` → «Организация» |
| Логин | `bootstrapAdminUsername` → `admin` |
| Пароль | `bootstrapAdminPassword` → `admin123` |

**Смените пароль** после первого входа (настройки пользователей) и в `server-config.json`.

## Конфиг (`server-config.json`)

| Ключ | Назначение |
|------|------------|
| `port` / `host` | Порт и адрес прослушивания |
| `mapEngine` | `yandex` или `leaflet` (офлайн/ортофото) |
| `yandexMapsApiKey` | Ключ Яндекс.Карт |
| `bootstrapAdminUsername` / `Password` / `FullName` | Первичный админ (создаётся при старте, если нет) |
| `organizationName` | Название единственной организации |

Лимиты объектов и одновременных пользователей в Portable **отключены**.
| `storage` | `json` (по умолчанию) или `mysql` |

Данные: `data/store.json` (или MySQL при `storage: mysql`).

## Лицензия и релиз для клиента

Разработка: в `server-config.json` можно `portableLicenseRequired: false`.

Выдача заказчику — только через сборку:

```bash
cd Portable
npm run release
```

Появится `releases/network-map-portable-…` (и `.zip`) с прошитым публичным ключом и `INSTALL.md`. Лицензию клиенту выдаёте в основной **site-admin → Лицензии Portable** по коду машины.

## Отличие от облачной версии

Облако (`volsmap.ru`) живёт в корне репозитория. `Portable/` — отдельное дерево для выдачи заказчику; синхронизация с основной версией вручную при обновлениях ядра карты.
